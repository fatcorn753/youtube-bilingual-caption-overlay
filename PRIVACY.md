# プライバシーポリシー / Privacy Policy

**日本語**

「YouTube 字幕オーバーレイ」は、個人情報・閲覧履歴・字幕の内容を収集、送信、保存しません。ネットワーク通信は一切行いません。

- 日本語訳は、Chrome 内蔵の翻訳 API を使い、端末内で行います。字幕が外部のサーバーへ送られることはありません
- 保存するのは、文字サイズ・テーマ・日本語訳の表示設定のみです。`chrome.storage.local` を通じて、利用者のブラウザ内にだけ保存されます
- 拡張機能は `https://www.youtube.com/` 上でのみ動作します。要求する権限は `storage` のみです

**English**

Bilingual Caption Overlay for YouTube does not collect, transmit, or store any personal data, browsing history, or caption content, and makes no network requests.

- Translation runs on your device using Chrome's built-in Translator API. Captions are never sent to any server.
- The only data stored is your text-size, theme, and translation on/off preferences, kept locally in your browser via `chrome.storage.local`.
- The extension runs only on `https://www.youtube.com/`. The only permission it requests is `storage`.
